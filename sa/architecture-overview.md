## 6. 關鍵流程 Sequence Diagrams（文字版）

### 6.1 STDIO 模式啟動流程

```
User -> CLI: mcp-database-server
CLI -> ConfigLoader: loadConfig(yaml_path)
ConfigLoader -> CredentialResolver: resolveCredentials(connections)
CredentialResolver -> EnvCredentialProvider: resolve("${MSSQL_PASSWORD}")
EnvCredentialProvider --> CredentialResolver: password_value
CredentialResolver --> ConfigLoader: resolved_connections
ConfigLoader --> CLI: ServerConfig
CLI -> ConnectionManager: createPools(connections, poolConfig)
ConnectionManager -> DriverFactory: createDriver(type)
DriverFactory --> ConnectionManager: IDriverAdapter
ConnectionManager -> ConnectionPool: initialize(driver, poolConfig)
ConnectionPool --> ConnectionManager: pool_ready
CLI -> ToolRegistry: registerTools([list_connections, describe_tables, query_database, mongodb_query, discover_schema])
ToolRegistry --> CLI: tools_registered
CLI -> MCPServer: start(StdioTransport)
MCPServer --> User: MCP Server ready (STDIO)
```

### 6.2 SQL 查詢執行流程

```
AIClient -> MCPServer: call tool "query_database" { connection_name, query, limit?, timeout_ms? }
MCPServer -> QueryDatabaseTool: execute(input)
QueryDatabaseTool -> ConnectionManager: resolveConnection(connection_name)
ConnectionManager --> QueryDatabaseTool: IDriverAdapter
QueryDatabaseTool -> SQLValidator: validate(query)
SQLValidator -> SQLValidator: parse SQL, detect statement type
  [if forbidden type] SQLValidator --> QueryDatabaseTool: SQLValidationFailed
  [if allowed type] SQLValidator --> QueryDatabaseTool: SQLValidationPassed
QueryDatabaseTool -> QueryDatabaseTool: clampLimits(limit, timeout_ms, serverLimits)
QueryDatabaseTool -> IDriverAdapter: execute(query, { limit, timeout })
IDriverAdapter --> QueryDatabaseTool: QueryResult { columns, rows }
QueryDatabaseTool -> QueryDatabaseTool: truncateIfNeeded(result, maxRows, resultSize)
QueryDatabaseTool -> AuditLogger: log({ timestamp, connection_name, query, row_count, execution_time, client })
QueryDatabaseTool --> MCPServer: QueryResult
MCPServer --> AIClient: MCP response
```

### 6.3 MongoDB 查詢執行流程

```
AIClient -> MCPServer: call tool "mongodb_query" { connection_name, collection, operation, filter, pipeline?, limit?, timeout_ms? }
MCPServer -> MongoDBQueryTool: execute(input)
MongoDBQueryTool -> ConnectionManager: resolveConnection(connection_name)
ConnectionManager --> MongoDBQueryTool: MongoDBDriver
MongoDBQueryTool -> MongoValidator: validateOperation(operation)
  [if forbidden operation] MongoValidator --> MongoDBQueryTool: MongoValidationFailed
  [if aggregate] MongoValidator -> MongoValidator: validatePipeline(pipeline)
    [if contains $out/$merge] MongoValidator --> MongoDBQueryTool: MongoAggregatePipelineRejected
  MongoValidator --> MongoDBQueryTool: MongoValidationPassed
MongoDBQueryTool -> MongoDBQueryTool: applyDefaults(limit=1000, maxTimeMS=30000)
MongoDBQueryTool -> MongoDBDriver: execute(collection, operation, filter/pipeline, options)
MongoDBDriver --> MongoDBQueryTool: QueryResult
MongoDBQueryTool -> AuditLogger: log(entry)
MongoDBQueryTool --> MCPServer: QueryResult
MCPServer --> AIClient: MCP response
```

### 6.4 HTTP 模式認證流程

```
Client -> HttpTransport: HTTP request with "Authorization: Bearer <api_key>"
HttpTransport -> RateLimiter: checkLimit(api_key, client_ip)
  [if exceeded] RateLimiter --> Client: 429 Too Many Requests
RateLimiter --> HttpTransport: allowed
HttpTransport -> ApiKeyAuthenticator: authenticate(authorization_header)
ApiKeyAuthenticator -> ApiKeyAuthenticator: extract token, compare with configured keys
  [if invalid] ApiKeyAuthenticator --> Client: 401 Unauthorized
ApiKeyAuthenticator --> HttpTransport: authenticated
HttpTransport -> MCPServer: forward MCP request
MCPServer --> HttpTransport: MCP response
HttpTransport --> Client: HTTP response
```

### 6.5 Credential 三層解析流程

```
ConnectionManager -> CredentialResolver: resolve(passwordRef="${MSSQL_PASSWORD}", config)
CredentialResolver -> CredentialResolver: detectProvider(config.credential.provider)

[Layer A: env (預設)]
CredentialResolver -> EnvCredentialProvider: resolve("MSSQL_PASSWORD")
EnvCredentialProvider -> process.env: get("MSSQL_PASSWORD")
  [if found] EnvCredentialProvider --> CredentialResolver: password_value
  [if not found] EnvCredentialProvider --> CredentialResolver: CredentialResolutionFailed

[Layer B: keychain (可選)]
CredentialResolver -> KeychainCredentialProvider: resolve("sales-db")
KeychainCredentialProvider -> OS_Keychain: getPassword("mcp-database-server", "sales-db")
  [if found] KeychainCredentialProvider --> CredentialResolver: password_value
  [if not found] KeychainCredentialProvider --> CredentialResolver: CredentialResolutionFailed

[Layer C: vault (企業選配)]
CredentialResolver -> VaultCredentialProvider: resolve("sales-db")
VaultCredentialProvider -> VaultAPI: GET /v1/secret/data/sales-db
  [if found] VaultCredentialProvider --> CredentialResolver: password_value
  [if unreachable] VaultCredentialProvider --> CredentialResolver: CredentialResolutionFailed
```

### 6.6 Schema Discovery 流程（含快取）

```
AIClient -> MCPServer: call tool "discover_schema" { connection_name, include_patterns?, exclude_patterns?, depth? }
MCPServer -> DiscoverSchemaTool: execute(input)
DiscoverSchemaTool -> SchemaCache: get(cacheKey)
  [if cache hit & TTL valid] SchemaCache --> DiscoverSchemaTool: cached SchemaOverview
  [if cache miss or expired]:
    DiscoverSchemaTool -> ConnectionManager: resolveConnection(connection_name)
    ConnectionManager --> DiscoverSchemaTool: IDriverAdapter
    DiscoverSchemaTool -> SchemaService: discover(driver, { include_patterns, exclude_patterns, depth })
    SchemaService -> IDriverAdapter: execute(metadata_queries)
    IDriverAdapter --> SchemaService: raw metadata
    SchemaService -> SchemaService: filterByPatterns, buildOverview, truncateIfExceedsMaxSize
    SchemaService --> DiscoverSchemaTool: SchemaOverview
    DiscoverSchemaTool -> SchemaCache: set(cacheKey, SchemaOverview, TTL=10min)
DiscoverSchemaTool --> MCPServer: SchemaOverview
MCPServer --> AIClient: MCP response
```

## 8. 安全機制摘要

| 層級 | 機制 | 說明 |
|------|------|------|
| SQL 語句層 | SQLValidator | 白名單：SELECT/SHOW/DESCRIBE/EXPLAIN；黑名單：INSERT/UPDATE/DELETE/DROP/ALTER/TRUNCATE |
| MongoDB 操作層 | MongoValidator | 白名單：find/aggregate/countDocuments/distinct/listCollections/listIndexes/explain |
| MongoDB Pipeline 層 | MongoValidator | 禁止 $out/$merge；可選限制 $lookup/$graphLookup |
| 查詢限制層 | QueryPolicy | max_rows=1000, timeout=30s, result_size=5MB, max_execution_time=60s |
| HTTP 認證層 | ApiKeyAuthenticator | Bearer token 驗證；進階：JWT/OIDC、mTLS |
| 速率限制層 | RateLimiter | per-key / per-IP |
| Credential 層 | CredentialResolver | 三層解析：env -> keychain -> vault；禁止 YAML 明文密碼 |
| 資料庫層 | DB RBAC | 雙保險：應用層攔截 + DB 唯讀帳號 |
